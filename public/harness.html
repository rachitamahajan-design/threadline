The harness

Every AI run ends as one honest line in a log.

Each check is plain code, not another prompt. What can't prove itself gets cut — and the record is written even if the process dies mid-run.

✓ When the model and a check disagree, the check wins

1No receipt, no ship

Every line must cite the transcript.

✓Ship sandbox keys by Friday ¶ 14:32
✕Team aligned on next steps no source → pruned

2Numbers are copied, never composed

Figures must match the transcript exactly.

¶ 21:07 — “the cap is $4,200 a month”
✓$4,200 a month
✕$4,000 a month not verbatim → pruned

3A second check reads every claim

Does the cited line actually say that? Drift gets blocked.

said: “let's consider launching”
✕decided to launch not supported → blocked

4No invented owners

Action items only go to people who were in the room.

✓Maya: draft the comparison table
✕John: draft it not a participant → Unassigned

5Empty beats invented

Not discussed → not in the notes. Cut lines are counted, never reworded.

✕Likely next steps… nobody said it → omitted
notes header: 2 lines dropped — no proof

6Retries fix, they don't re-roll

The failed check is fed back verbatim. You only see the clean result.

attempt 1 → "$4,000" not verbatim in ¶ 21:07 attempt 2 → ok · the only one you see

7A dead checker can't delete

If the check itself fails, nothing is removed — it ships marked for review.

✓kept, flagged needs review unverified ≠ wrong

8Every run is on the record

Budgeted, four possible endings, logged even if the process dies mid-run.

The console

The record is a dataset. Read it like one.

Every run leaves one row in the runs table. One row powers the retry button; fifty rows answer the operational questions — is it shipping, what is it costing, which gate is firing.

What one row buys you

  • The retry button. args holds exactly what to re-dispatch — same work, fresh budget, its own new record.
  • The bill. Tokens and cost are attributed per run, priced from config — the charts below just add them up.
  • The audit. Outcome plus a structured reason, written even for a kill -9 mid-run.
  • This console. Everything below is drawn live from rows like this one — no extra instrumentation.
